我的第一個前端個人網站

學習筆記｜FDE101

這是我在 FDE101 課程中製作的個人作品集。 比起只有一張漂亮的首頁，我更希望網站真的能操作、 能維護，也能讓不同需求的使用者閱讀。

從頁面架構開始

網站採用多頁式 HTML 結構， 左側固定導覽，右側保留文章閱讀空間。 側邊選單使用原生連結， 因此不依賴 JavaScript 也能切換頁面。

把無障礙放在設計起點

從正確的標題層級、跳至主要內容、 目前頁面提示到鍵盤焦點樣式， 這些都是一開始便納入的需求。 接下來也需要透過實際的鍵盤與輔助科技測試來驗證。
