那時候，我還不太懂什麼是固定 IP

學習筆記｜FDE101

有時候回頭想想，自己接觸資訊技術的起點，好像不是什麼特別正式的課程。 而是某一天，教授換了電腦以後，辦公室的網路經常連不上網。 說起來有點好笑，那時候的我，連固定 IP 到底是什麼，都還只有模模糊糊的概念，卻已經開始和網路問題奮戰。

一、教授的網路，怎麼又斷了？

在研究室工作的時候，教授辦公室的網路偶爾會出現連線異常。 當時我沒有接受過完整的網路管理訓練，面對這種狀況，能想到的方式其實很有限。 既然網路不通，那就先從看得見、摸得到的地方開始吧。 檢查網路線、重新插拔、更換線材，再試著重新啟動設備。 這些方法雖然基本，至少是當時我比較有把握，也能確認操作結果的事情。 奇怪的是，無論怎麼測試，設備似乎都沒有明顯問題。 網路有時候正常，有時候卻又突然斷線。 最讓人困惑的，就是這種無法穩定重現的問題。 明明測試時都沒事，教授進研究室時卻總是又出狀況？ 更不巧的是教授需要我去處理的時候我可能會在別的教室上課或兼任助教， 事情真是有些尷尬。

二、從一台影印機開始的聯想

我一直記得，學校助理辦公室的影印機旁，曾經特別提醒大家要注意自己的 IP 設定。 大意是，如果使用了不適當的 IP 位址，可能會和影印機使用的位址發生衝突，影響設備正常運作。 老實說，當時我並沒有真正弄懂其中的原理，只是把這件事情記在心裡。 後來，遇到教授辦公室的網路異常，我開始上網查找 IP 設定、網路連線與相關的控制介面， 試著理解究竟有哪些原因會影響連線。但知道某個設定可能有問題，跟真的有能力安全地修改它，是兩回事。 畢竟那些是學校的設備，我並不清楚整體網路配置，也沒有把握更動設定後會造成什麼影響。 萬一原本只是網路斷線，最後卻因為我亂改設定，讓系上的其他設備也一起出問題，那可就真的 QQ 了。 所以，我沒有貿然更動不熟悉的網路設定，而是先保留這個疑問。

三、另一間教室，怎麼也有類似的問題？

事情的轉折，發生在另一份工作，也就是兼任助教的時候。 當時我同時兼任助教，上課的教室也經常遇到類似的網路問題。(正巧在研究室隔壁喔) 一開始，我沒有把這兩件事情聯想在一起。 畢竟一邊是教授辦公室，一邊是上課教室，看起來是不同的環境。 直到某次，我突然想起之前在教授辦公室測試網路時，另一間教室剛好沒有使用。 那時候，網路測試的結果都很正常。 可是另一間教室開始使用設備後，卻可能又出現連線異常。 腦中忽然浮現之前影印機的提醒。 「等等，會不會是 IP 位址的問題？」 如果兩個地方的設備使用了相同的位址，有沒有可能在同時連線時互相影響？ 這個念頭讓原本看似沒有關聯的幾件事情，突然有了可以連接的線索。 雖然當時還不清楚具體的網路配置，也無法單靠這些觀察就確認根本原因， 但至少，我開始有了不同於硬體故障的排查方向。

四、原來，測試正常不代表真的沒有問題

後來學習更多資訊技術知識，再回頭看這段經歷，才逐漸理解當時的疑問。 在特定的網路環境下，如果兩台設備被設定成相同的 IP 位址，就可能產生位址衝突，導致連線不穩定。 如果其中一台設備沒有連線，另一台可能暫時正常；但當兩台設備同時使用網路時，問題才有機會浮現。 不過，這只是可能的情境。 實際上，網路斷線還有許多其他原因，例如設備、線路、網路配置或連線服務本身的問題。要確認是不是 IP 衝突， 仍然需要檢查實際設定與相關資訊。 因此，我不會說自己當年已經完整查明故障原因。 比較精確的說法是：我從不同場所反覆發生的異常中，找到了一個值得進一步驗證的假設。 而這件事情，也讓我重新理解了「排查」的意思。 有時候，我們以為自己已經測試過設備，問題就應該被排除了。 但如果沒有考慮到問題發生的時間、環境和條件，可能只是剛好沒有碰到讓異常出現的情境。 原來，除了知道怎麼測試，還要知道自己究竟測試了什麼。

五、從不敢亂動設定，到開始理解背後的原理

現在回頭看，當時的自己其實有很多不懂的地方。 不清楚固定 IP 的完整概念，也不知道如何系統性地檢查網路設定。 但我還記得自己努力查資料、反覆確認硬體，又突然將不同教室的情況聯想在一起的過程。 那時候的學習，並沒有明確的章節或進度。 比較像是生活突然丟來一道題目，而我只能拿著手邊有限的知識，一點一點拼湊答案。 現在開始接觸 Linux、網路指令與程式設計，再回頭理解這些曾經遇過的問題，反而有種奇妙的感覺。 以前只知道「網路又斷了」，現在開始知道可以從哪些角度觀察網路連線、IP 設定與設備狀態。 以前遇到不熟悉的設定，只能先停在那裡；現在則希望透過學習，慢慢建立判斷與操作的能力。 當然，不懂的事情還是很多。但我想，技術學習最有趣的地方之一，就是某天突然發現： 原來以前碰過、卻一直沒有真正弄明白的事情，現在終於開始能看懂一點了。 那些當時留下的疑問，似乎也隨著新的知識，一點一點找到了自己的位置。 而我大概還會繼續這樣，一邊學、一邊查資料，偶爾被問題困住，再慢慢把它們解開。
